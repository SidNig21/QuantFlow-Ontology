# QuantFlow Research Library

> Curated from a large Safari tab dump. URLs are deduplicated, tracking parameters are stripped where possible, and resources are grouped by research domain.

**Library size:** 286 unique URLs extracted from 289 captured URL entries.

## How to use this library

- **🔥 Priority:** Start here for QuantFlow architecture, agent runtimes, ontology/shared truth, RL infrastructure, and trading systems.
- **🧠 Research:** Papers, technical references, and deep conceptual material.
- **🛠 Build:** Repositories, SDKs, APIs, and infrastructure worth testing.
- **📚 Reference:** Valuable background or future research.
- **🧹 Search:** Google searches retained separately so the original research trail is not lost.

## Recommended research path

1. **QuantFlow / Core Architecture** → understand the current system.
2. **Ontology / Shared Truth** → compare QuantFlow's Kernel/ontology model with Palantir-style operational ontologies.
3. **Agent Runtime / Actors** → study durable state, actors, Envoy, AgentOS, and orchestration.
4. **RL / RLVR / Training** → understand how agents can improve through environments and feedback.
5. **Quant Trading / Financial ML** → connect the architecture to the original quantitative-agent domain.
6. **Models / Fine-Tuning / Inference** → determine what should run locally, remotely, or through routed model infrastructure.
7. **Visual Design / UI** → translate the architecture into the operator-console interface.
