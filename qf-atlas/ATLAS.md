## Read this first

QuantFlow is an Electron research console. Work flows across three hops:

```
renderer (canvas, tiles, dock)   →   preload (contextBridge)   →   main (handlers)   →   Kernel
     a window surface                a named IPC channel          ipcMain.handle       execute()
```

A **wire** is one IPC channel traced across those hops. A wire is only as good as its weakest
hop, and the atlas classifies every one of them:

| Status | Meaning | Count |
|---|---|---:|
| `live` | renderer calls it, preload forwards it, main handles it | 110 |
| `unused` | preload exposes it and main handles it, but no renderer file calls it | 13 |
| `unreached` | main registers a handler that nothing forwards to | 5 |
| `dead` | preload calls a channel no handler registers — **fails at runtime** | 0 |

## Staying true

```bash
bun qf-atlas/generate.mjs           # rewrite the map from source
bun qf-atlas/generate.mjs --check   # fail if the committed map is stale
```

`--check` regenerates in memory and compares. If the code moved and the map did not, it exits 1.
That is the whole contract: **the map cannot lie for longer than one commit.**
