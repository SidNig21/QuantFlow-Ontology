## Revision note (2026-07-25)

The first issue of this order carried a deliverable 2 — *"add `report` + `publish_report` that
refuses without a passing evaluation"* — that was **struck as unbuildable**. Three measured
reasons, all confirmed at source:

1. `artifact.kind` already contains `"report"`, and `artifact`'s own description reads
   *"Reports are artifacts, not a separate type."* Adding a `Report` object type would have been
   red-lighted by this order's own Silo lint (deliverable 5).
2. **No link in this repo is writable.** `golden/migration.sql:369` generates a `links` table
   with a CHECK over all 13 link names; a repo-wide grep finds **zero** reads and **zero**
   writes. `execute()` (`packages/qf-kernel/src/execute.ts:103`) branches exactly two ways —
   creation and transition. There is no link branch. A gate that reads "a linked evaluation"
   has nothing to read.
3. `record_evaluation` is **not a registered command** — it is one of nine defined actions with
   no `commands.ts` entry, so `execute()` throws `Unknown command`. No evaluation can be
   recorded, so none can be checked.

The mechanical publication gate is real and still wanted. It lands at **WO-110**, after the
write path exists (**WO-103**). See `docs/orders/SCOPES.md`. Nothing of value was dropped —
it was moved to the rung where it is possible.

## Deliverables

Move the `defineObject` / `defineLink` / `defineAction` blocks into `src/ontology/research.ts`,
`src/ontology/market.ts`, `src/ontology/agent.ts`. Links and actions live with their owning
plane; a cross-plane link lives where its `from` side lives. `schema.ts` becomes a pure
aggregator re-exporting the same names, so **every existing import and the codegen path work

**Proof of zero change: the golden tests.** `src/generate.test.ts` compares all four generated
artifacts byte-for-byte against `golden/`. If this deliverable changes one byte of `golden/`,
you moved something you should not have. Do not paste a diff command — state that the four
golden tests passed *without regenerating*, which is the stronger claim.

**Commit this deliverable alone, first.** Deliverables 2–5 change the schema and will
legitimately move `golden/`. Bundled into one commit, the zero-change proof is destroyed and
unrecoverable.

### 2 · Descriptions become agent context (research + agent planes only)

know to act on this correctly?*

description ends *"Never clone types per pipeline step"* — that is the bar. A description
restatable from the field name is a defect ("The name of the workspace" fails).

## Gates

**G1 · Lint falsification (builder-run).** Three sabotages each go red, then restore to green:
a missing description · a `backtest_run` clone · a property removed from an `active` fixture
type. Bait transcripts in the report, both directions.

**G2 · The cold-read protocol (verifier-run, not CI).** Ship `qa/fixtures/charter-101.md`
containing the protocol below. A cold agent is given **only the three plane files** — no
database, no other docs — and asked:

> *"Using only these type definitions: I want to know which runs testing a given hypothesis
> produced a supporting evaluation, and which published artifact those evaluations gated. Name
> the exact types, the exact links, and the exact field and value that means 'supporting'. If
> anything needed is missing from these files, say what."*

This tests **descriptions, not data** — which is why it needs no rows and works today.

Pass = the agent names `hypothesis`, `run`, `evaluation`, `artifact`; names `tests`, `produces`,
`evaluated_by`, `derived_from`; and identifies **`evaluation.verdict === "supports"`** as the
predicate. `confidence` is a separate 0–1 field and is **not** the gate — an agent that
conflates them found a description defect.

A wrong answer is a **description defect** — fix the description, not the protocol.
**Escape hatch:** if the correct answer is genuinely unexpressible because the schema lacks the
field or link, that is a **schema finding to log in your report**, not a description to reword.
Bonus, not required: an agent that notices the links are declared but unwritable has read well.

**G3 · Suite.** Full suite green, cold (`bun install --frozen-lockfile` from a clean worktree).
State the count before → after. It **must grow** — new types generate new rows in the golden
docs; if it does not grow, deliverables 3–4 did not land.
