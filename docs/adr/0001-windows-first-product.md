# Native Windows is the primary product target

status: accepted

On 2026-08-02 the founder reversed the Linux-first decision: QuantFlow is developed, packaged,
run, and accepted natively on Windows 11 first because that is the operator's real environment and
the product must work where it is actually used. WSL and Linux remain secondary compatibility
targets, but neither can substitute for a founder-visible Windows proof; this decision supersedes
all prior Linux-first and WSL-continuation guidance.
