# ADR-0005 — One Canvas with governed multi-runtime collaboration

status: accepted
date: 2026-09-07
decision-maker: founder

QuantFlow has one Canvas workspace. A Mission is an internal Kernel scope created from Ryan's inquiry, never a screen, mode, tile, or replacement world; Inspect reveals selected detail, Evaluation, history, and lineage without rearranging the desk. Kernel objects do not become tiles merely because they exist: the Canvas shows only the Director, deliberately recruited Participants, deliberately opened capabilities, and useful outputs Ryan or the Director chooses to surface. Cold open is an empty Canvas with the Director ready; closing QuantFlow terminates all owned processes; prior institutional work remains retrievable from the Kernel but does not repopulate the Canvas automatically.

Hermes, Claude Code, Codex, and future runtime species collaborate as governed Participants while retaining separate private contexts. They share only bounded institutional context read from the Kernel. The Director delegates by default; an authorized Participant may delegate directly through an exact Task naming predecessor work, while the Director and Ryan retain visibility and steering authority. Durable handoff requires an immutable Artifact; peer messages and terminal prose are notifications, not truth. Cables are absent by default, show eligible collaboration only around a selected visible surface, and emphasize actual delegation, capability use, or Artifact handoff; they never render the full Ontology graph.

This decision supersedes ADR-0003 only where ADR-0003 authorized persistent general-purpose cable UI. The experimental `connection` schema may remain until separately adjudicated, but it does not authorize default Canvas wiring or a second collaboration truth.
