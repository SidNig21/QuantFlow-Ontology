# History — superseded, not binding

Everything under `docs/history/` is kept for its reasoning, not its direction.

**Nothing here is authority.** No agent may select work from a file in this tree, and no plan
here reactivates by being read. If a document here disagrees with `START_HERE.md`,
`docs/DOCTRINE.md`, or `docs/orders/NEXT.md`, the live document wins without argument.

Archived 2026-08-03 under DOCTRINE amendment A9, which moved build authority to the single
active rung named in `docs/orders/NEXT.md`. Nothing was deleted.
