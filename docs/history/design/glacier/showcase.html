Dock — what changed

Every box is gone. No cards, no chips, no segmented control, no bordered rows. The old dock was eight bordered rectangles stacked in a bordered panel — that nesting is what made it read as an admin template. Hierarchy is now scale and density: a 21 px masthead, a loose ask, a typographic launcher, a 26 px-row ledger.

The spawn buttons are gone too. The row is the button — full-bleed hover, ice edge on the left. Four filled pills competing with four names is a fight the names should never have been in.

Sessions became a ledger. Fixed columns, tabular figures, real exit codes instead of a uniform CLOSED chip — exit 130 and exit 1 are information a green pill was actively hiding.

File rail — what did not

Tabs, search, add-workspace, tree, counts: unchanged in structure. Only the palette, the row hover, and the selection marker moved. Selection is a 2 px ice edge plus a tint rather than a full-bleed highlight, so long filenames stay readable.

Canvas

The watermark stays on the canvas and no longer bleeds through tiles — tiles are opaque, so they read as objects on the surface. The cable is drawn beneath tiles and above the grid, exits a lit E node and enters a lit W node. Unlit nodes are free ports.
